# Splunk Facts Verified Against Official Documentation

The key SPLK-1001 facts used in these notes, each checked against Splunk's own documentation (docs.splunk.com / help.splunk.com) in October 2026. Splunk's docs change over time, so always confirm against the current version.

> [!NOTE]
> **Docs vs. course wording: timeline zoom.** The Splunk Core User course teaches that *Zoom to selection* and *Zoom out* both re-run the search. Current docs say *Zoom out* changes the Time Range Picker, and describe *Zoom to selection* as filtering the existing results.
