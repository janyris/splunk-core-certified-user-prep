# Splunk Core Certified User (SPLK-1001) Study Notes

Study notes and original practice questions I used to prepare for, and pass, the **Splunk Core Certified User (SPLK-1001)** exam in October 2026.

> [!NOTE]
> **How these were made:** written with AI assistance (Claude) while I studied, then fact-checked against Splunk's official documentation. Unofficial: not affiliated with or endorsed by Splunk. **No real exam questions** are included.

## How I'd use it

1. Read the topic note, then answer its self-check out loud.
2. Do that topic's section in the practice questions.
3. Drill the reference sheets: [SPL commands](study-guide/09-Reference_SPL-Commands.md), [defaults and numbers](study-guide/10-Reference_Defaults-and-Numbers.md), [confused pairs](study-guide/11-Commonly-Confused-Pairs.md).
4. Last day: only the [high-yield sheet](study-guide/13-Final-Review_High-Yield-Sheet.md).
